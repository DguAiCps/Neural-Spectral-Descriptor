## 0. 목적

최종 시스템의 성능이 어디에서 오는지 나눈다. 세 질문에 답한다.

1. **후보 수인가, 상보성인가 (C2)**: 두 색인 합집합의 이득이 후보가 두 배라서인가, 두 색인이 서로 다른 정답을 찾아서인가. 총 후보 수를 같게 맞춘 뒤 최종 첫 번째 후보 정답률(R@1)로 비교한다.
2. **궤적 문맥이 최종 성능에 기여하는가 (C4)**: 최종 시스템(보조 색인, 점수 융합, 순환 정렬 포함)에서 검색 키의 문맥을 빼면 얼마나 달라지는가.
3. **근거가 약한 부품은 일하는가 (탐색)**: 학습형 간선 재선택, 두 번째 통과, 재계량, 검색 키의 회전 불변 블록.

### 결정 기록 (2026-09-29, 사용자 결정)

| 항목 | 결정 |
|---|---|
| 범위 | 확장안: C2·C4에 더해 간선 재선택 변형, 재계량 끔, 문맥만 키까지 |
| 융합 가중치 | 두 규칙 모두. 행마다 검증셋에서 다시 고르는 규칙이 주 결과, 현재 고정 가중치를 쓰는 규칙이 참고 결과 |

## 2. 비교할 것

### 2.1 검색 키 변형

| 이름 | 정의 | 만드는 곳 |
|---|---|---|
| K1 현재 | 학습형 간선 재선택 뒤 두 번째 통과 출력 f (416개) | 도커. `_pd_branch_fusion.nsd_embedding_pd`와 같은 계산 |
| K2 코사인 재선택 | 두 번째 통과에 넣는 간선 10개를 분류기 확률 대신 첫 통과 키 코사인 상위 10개로 고름 | 도커. `scripts/_edge_ablation_fix8.py:embeddings_three_ways`의 `cosine10`과 같은 방식(ω와 분류기는 장소 분리 산출물) |
| K3 첫 통과만 | 두 번째 통과 없이 첫 통과 출력 f0 | 도커. 같은 함수의 `pass1` |
| K4 재계량 끔 | K1에서 회전 불변 블록의 ω만 뺀 키: normalize([normalize(d); α·ĉ]). 그래프와 간선 선택은 K1과 같다 | 호스트. K1과 캐시의 d로 계산 |
| K5 문맥 제거 | normalize(ω⊙d) (288개). 그래프를 쓰지 않는다 | 호스트. 시드와 무관 |
| K6 문맥만 | ĉ (128개, 길이 1) | 호스트. K1에서 계산 |

K4와 K6의 α와 ĉ는 K1에서 다시 얻는다. 모델 출력이 [normalize(ω⊙d); α·normalize(c)]를 이어 붙여 길이를 1로 맞춘 것이므로(`src/gnn/model.py:1098-1122`, `_pd_branch_fusion.py:160`), α = ‖f[288:]‖ / ‖f[:288]‖, ĉ = f[288:] / ‖f[288:]‖이다.

## 3. 융합 가중치 규칙

### 3.1 주 규칙: 행마다 다시 고름
- 검증셋 4개 시퀀스에서 89개 격자의 모든 가중치로 R@1을 구한다.
- 질의 가중 R@1을 세 시드에 걸쳐 더한 값이 가장 큰 가중치를 고른다. 같은 값이면 격자 정렬 순서에서 앞의 것을 고른다(`scripts/_pd_tuple_select.py`와 같은 규칙).
- 정렬 끔 행은 스펙트럼 상관과 열 정렬 가중치가 0인 격자 부분집합에서 고른다.
- K5와 보조 크기 색인은 시드와 무관하므로 세 시드 값이 같다. 규칙은 그대로 적용한다.

### 3.2 참고 규칙: 현재 가중치 고정
- NSD (2, 1, 2, 2), NSD-H (2, 1, 2, 0.5)를 그대로 쓴다(`results/pd2026/tuple_selection.json`).
- 정렬 끔 행은 두 정렬 가중치만 0으로 바꾼다.

### 3.3 동결
- 두 규칙의 선택 결과를 `results/decomp2026/selection.json`에 쓰고 해시를 기록한 뒤에 시험셋을 처음 계산한다. 선택 뒤에는 바꾸지 않는다.

- **주 지표**: 시험 37개 시퀀스의 6묶음 평균 R@1(원고 Table 1과 같은 집계).
- **보조 지표**: 37개 시퀀스 평균, 질의 가중 평균, R@5, 묶음별 R@1, 실제 후보 수(평균, 95분위).

## 5. 확증 비교

아래 네 비교만 확증 비교다. 주 규칙(§3.1), 정렬 켬, 절반씩 B=200 기준이다. 나머지는 모두 탐색 결과로 표시한다.

| 이름 | 비교 | 답하는 질문 |
|---|---|---|
| H1-NSD, H1-NSD-H | 절반씩 B=200 대 한 색인 B=200 (키만과 보조만 중 검증셋 점수가 높은 쪽을 §3.1과 같은 방식으로 미리 고름), 검색 키 K1 | 같은 후보 수에서 두 색인이 한 색인보다 나은가 (C2) |
| H2-NSD, H2-NSD-H | K1 대 K5, 절반씩 B=200 | 최종 시스템에서 문맥이 성능을 올리는가 (C4) |

- 차이는 6묶음 평균 R@1의 포인트 차이(앞 − 뒤)와 95% 신뢰구간으로 보고한다.
- 네 비교의 p값은 Holm 방법으로 보정한다.
- "차이 없음" 판정은 하지 않는다(§0 결정 기록).

## 6. 통계 방법

- **짝지은 이동 블록 부트스트랩**: 시퀀스마다 질의 순서대로 길이 50의 블록을 복원 추출해 원래 질의 수만큼 채운다. 두 비교 대상에 같은 추출을 쓴다. 반복 10,000번, 난수 시드 20260929.
- 반복마다 시퀀스별 R@1 → 묶음 평균 → 6묶음 평균을 다시 계산해 차이를 구한다.
- 질의별 값은 시드에 따라 달라지는 행이면 세 시드 정답 여부의 평균(0, 1/3, 2/3, 1)이다.
- 95% 신뢰구간은 백분위수 구간이다. 양쪽 p값은 2 × min(P(Δ* ≤ 0), P(Δ* ≥ 0))이고 유한 표본 보정(+1)을 쓴다. 0인 p값은 적지 않는다.
- 민감도 분석: 블록 길이 25, 100.
- 탐색 비교에는 신뢰구간만 적고 유의성 주장을 하지 않는다.
