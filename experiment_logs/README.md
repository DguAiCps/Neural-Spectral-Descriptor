# 실험 일지 (Experiment Logs)

실험이 완료될 때마다 이 폴더에 일지를 하나씩 남긴다. 릴리스 번들에는 포함되지
않는다 (`make_release_bundle.sh`가 명시 목록 방식이라 자동 제외).

## 규칙

- 파일명: `YYYY-MM-DD_짧은-주제.md` (실험 완료일 기준)
- 하나의 실험(또는 밀접한 실험 묶음)당 한 파일
- 간단히: 아래 4개 섹션이면 충분. 표/수치는 결과 JSON·로그 경로를 함께 남긴다

## 템플릿

```markdown
# (제목)

- 날짜: YYYY-MM-DD
- 관련 브랜치/커밋:

## 왜 (진행 이유)

## 설정 (파라미터)

## 결과

## 결론 / 다음
```
